# Phenotype-Aware Genomic Surveillance of *Klebsiella pneumoniae*

This repository contains the analysis scripts supporting the manuscript:

**Phenotype-Aware Genomic Surveillance Reveals Siderophore-Associated Virulence–Resistance Backgrounds in *Klebsiella pneumoniae***

The workflow integrates whole-genome sequencing data, antimicrobial susceptibility phenotypes, antimicrobial resistance determinants, virulence factors, siderophore systems, multilocus sequence types, capsule loci, and phylogenomic analyses.
